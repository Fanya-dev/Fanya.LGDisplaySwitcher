# Fanya.LGDisplaySwitcher

Windows-утилита для автоматического переключения конфигурации дисплеев между двумя сохраненными профилями: рабочим и игровым. Переключение выполняется по сетевой доступности LG TV: если телевизор доступен по сети, применяется игровой профиль, если недоступен, применяется рабочий.

Проект написан на C# под .NET 9 и использует библиотеку DisplayConfig (PowerShell модуль) для чтения и применения конфигурации дисплеев Windows.

## Что умеет

- Сохранять текущую конфигурацию дисплеев в рабочий профиль.
- Сохранять текущую конфигурацию дисплеев в игровой профиль.
- Запускаться в фоновом режиме и периодически проверять доступность телевизора.
- Автоматически применять нужный профиль при изменении состояния телевизора.
- Добавляться в автозапуск Windows через реестр текущего пользователя.
- Позволять вручную сменить IP-адрес телевизора и вручную применить любой из двух профилей.

## Как это работает

Приложение хранит два файла профилей в папке рядом с исполняемым файлом:

- workProfile.json
- tvProfile.json

Во время фоновой работы утилита пытается установить TCP-соединение с телевизором по адресу из Config.json на порту 3001. Если соединение успешно, считается, что ТВ доступен, и применяется игровой профиль. Если соединение недоступно, применяется рабочий профиль.

Смена профиля происходит только при изменении состояния относительно последней сохраненной проверки.

## Требования

- Windows 10/11
- LG TV или другое устройство, доступность которого можно проверять по сети

## Пункты меню

- 1. Сохранить текущую конфигурацию как рабочий профиль.
- 2. Сохранить текущую конфигурацию как игровой профиль.
- 3. Добавить или убрать утилиту из автозапуска.
- 4. Запустить фоновый мониторинг.
- 5. Изменить IP-адрес телевизора.
- 6. Вручную применить рабочий профиль.
- 7. Вручную применить игровой профиль.

## Запуск

Обычный запуск открывает консольное меню.

1-2 пункты используются для создания слепка профилей.
3 пункт для добавления утилиты в автозапуск с параметром --service(скрывает отображение консоли)
4 запускает работу скрипта с выводом логов в консоли, для проверки настроек
5 установка IP адреса телевизора
6-7 пункты для ручного переключения профилей

Запуск с параметром `--service` запускает приложение в фоне без вывода консоли

## Настройка

1. Запустите приложение.
2. Выключите телевизор.
3. Зайдите в Параметры - Система - Дисплеи
4. Выберите дисплей телевизора, в пункте настроек нескольких дисплеев выберите "Отключить дисплей" (Disconnect this display)
5. Настройте оставшиеся монитор(ы) как бы вы использовали их при работе (или при выключенном телевизоре в принципе)
6. Сохраните как РАБОЧИЙ профиль
7. Включите телевизор
8. На телевизоре в настройках сети найдите IP адрес вашего ТВ
9. Выберите пункт "Изменить IP-адрес телевизора", впишите IP адрес телевизора
10. Зайдите в Параметры - Система - Дисплеи
11. Отключите все дисплеи кроме дисплея телевизора
12. Настройте дисплей телевизора на ваш вкус
13. Сохраните как ИГРОВОЙ профиль
14. Проверьте работу профилей используя пункты для ручной смены профилей
15. Если вас всё устраивает, запустите фоновый мониторинг из под меню, если телевизор был включен, автоматически переключится в ИГРОВОЙ профиль. Выключите телевизор, в течении 1-3 секунд приложение должно переключиться на РАБОЧИЙ профиль
16. Если всё исправно работает, перезайдите в приложение, и добавьте утилиту в автозапуск

## Конфигурация

Файл Config.json создается автоматически рядом с исполняемым файлом при первом запуске.

Пример:

```json
{
	"InAutoStart": false,
	"TVIP": "10.2.0.8",
	"LastTVState": false,
	"TimeToPingMs": 2000,
	"PingTimeout": 1000,
	"Debug": false
}
```

Назначение полей:

- InAutoStart: признак, добавлена ли утилита в автозапуск.
- TVIP: IP-адрес телевизора.
- LastTVState: последнее известное состояние доступности ТВ.
- TimeToPingMs: интервал между проверками в миллисекундах.
- PingTimeout: таймаут сетевой проверки в миллисекундах.
- Debug: зарезервированное поле, сейчас отдельно не используется.

## Автозапуск

Приложение добавляет себя в:

```text
HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
```

В реестр записывается команда запуска исполняемого файла с аргументом --service.

## Файлы профилей

После сохранения профилей рядом с приложением появляются:

- workProfile.json
- tvProfile.json

Именно они используются для последующего переключения конфигурации дисплеев.

Если одного из файлов нет или он поврежден, применение соответствующего профиля завершится ошибкой.

## Ограничения

- Утилита работает только с двумя профилями.
- Проверка доступности выполняется не через WebOS API, а обычным TCP-подключением к порту 3001.
- Проект ориентирован на Windows, так как использует Windows DisplayConfig и реестр Windows.
- Для корректной работы профили нужно сохранять на той системе и в той конфигурации устройств, где они будут применяться.
- Если порядок или состав подключенных дисплеев сильно изменится, сохраненные профили могут перестать подходить.

## Структура проекта

- Program.cs: точка входа, меню и фоновый цикл мониторинга.
- Utilities.cs: проверка доступности ТВ и применение профилей дисплеев.
- Config.cs: загрузка и сохранение Config.json.
- AutoStartManager.cs: работа с автозапуском через реестр Windows.
- lib/DisplayConfig.dll: внешняя библиотека для чтения и применения DisplayConfig.
